Copying Telegram Signals to Indian Brokers: Setup Notes

Many Indian trading groups on Telegram post calls for Nifty, Bank Nifty and stock options. Placing those orders by hand in Zerodha, Upstox or Angel One takes time, and option prices move fast. A copier can place the order for you, but the Indian market has details that a forex copier never had to handle.

Broker API and the daily login

Most Indian brokers give API access through an app or developer console. The access token usually lasts one trading day, so the copier needs a morning login step. Find out how your copier handles it and what happens if the login fails.

Option symbols

A call like "Bank Nifty 48000 CE" needs the expiry date and the exact trading symbol that the broker uses. The copier has to pick the right weekly or monthly expiry. Check its choice on a few signals before you trust it.

Lot sizes

F&O contracts trade in lots, and lot sizes change from time to time. Set your quantity in lots, and make sure the copier uses the current lot size for each index.

Product type

Intraday orders use MIS, while carry-forward F&O positions use NRML. The wrong product code gets rejected or squared off at the end of the day. Choose one per channel.

Order type

Market orders fill fast but can slip on thin strikes. Limit orders protect the price but may not fill. Some copiers let you place a limit order with a small buffer above the signal price, which is a fair middle ground.

Exit messages

Groups post "book profit", "exit half" or "SL hit". The copier should match those to the open position.

Start with one lot

Run the copier with a single lot for a week. Compare each Telegram call with the order in your broker's order book.
